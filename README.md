## Even-Odd Checker (Python Program)
Technologies Used
Python (Basic programming language)
Input/Output functions
Conditional statements (if-else)
Arithmetic operator (%)

## How it Works
The program asks the user to enter a number.
It converts the input into an integer using int().
It checks whether the number is divisible by 2 using the modulus operator %.
If the remainder is 0, the number is Even.
Otherwise, the number is Odd.
The result is displayed on the screen.

## Output
```
Example 1:
Ek number enter karo: 4
Yeh number Even hai.
Example 2:
Ek number enter karo: 7
Yeh number Odd hai.
```
